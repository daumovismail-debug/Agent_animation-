# Agent Animation — генератор промтов для ИИ-видео (Grok)

Агент превращает идею в полный набор промтов под **Grok**: сначала
**картинка** (ключевой кадр), потом **анимация** (image-to-video),
плюс **реплики** если ролик разговорный.

Перед генерацией задаёт уточняющие вопросы по тем местам идеи,
которые ты не договорил.

Работает на **Claude Opus 4.7** с включённым extended thinking (high).
Расход идёт **с твоей Pro/Max подписки** (через Claude Agent SDK).

## Как это работает

```
твоя идея
   ↓
[1] Claude анализирует идею и задаёт уточняющие вопросы
    (с готовыми вариантами ответа на каждый)
    + сам определяет, разговорный ли это ролик
   ↓
[2] Сценарий: title + character_anchor + сцены + реплики
   ↓
[3] Для каждой сцены — промт для КАРТИНКИ (ключевой кадр в Grok Imagine)
   ↓
[4] Для каждой сцены — промт для АНИМАЦИИ (image-to-video в Grok)
   ↓
output/<slug>.md   ← читать глазами, копировать в Grok
output/<slug>.json ← структурированно, для дальнейшей автоматизации
```

Если на старте флаг is_dialogue_heavy = true:
- задаются доп. вопросы про голос/язык/тон
- в каждой сцене появляются реплики (speaker + text + emotion)
- в animation-промте упоминается артикуляция/мимика говорящего

## Установка

```bash
pip install -r requirements.txt
```

### Авторизация (расход с подписки)

```bash
# Один раз залогинься через Claude Code CLI
claude login
```

После этого вызовы Claude будут списываться с твоей **Pro/Max подписки**,
а не с API-баланса.

### Fallback на API-ключ

Если Claude Agent SDK недоступен — агент автоматически переключится на
обычный Anthropic SDK:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

## Telegram-бот

Тот же агент, но в чате:

```bash
export TELEGRAM_BOT_TOKEN=<токен от @BotFather>
python -m agent.bot
```

В чате никаких команд кроме `/start` — всё кнопками:

1. **Отправь идею** одним сообщением
2. Бот покажет **меню настроек** где каждая опция меняется по тапу:
   - 🎨 Стиль (cinematic / anime / 3d / realistic / cartoon)
   - 🎬 Сцен: −/+
   - 🖼 Кадров/сцену: auto / 1 / 2 / 3
   - 📐 Формат: 16:9 / 9:16 / 1:1
   - ⏱ Длительность сцены: −/+
3. Жмёшь **🚀 Поехали**
4. Бот задаёт уточняющие вопросы **с кнопками** (или ✏ свой / ⏭ пропустить)
5. Получаешь результат: блок на каждую сцену + `.md` + `.json`

### Режимы кадров

- **auto** — Claude для каждой сцены сам решает, сколько кадров нужно
  (1-3). Простая сцена → 1, движение камеры → 2, длинная с событиями → 3
- **1** — всегда один ключевой кадр (быстро, дёшево)
- **2** — всегда start + end (хорошо для image-to-video)
- **3** — всегда start + middle + end (для сложных сцен)

## Использование CLI

```bash
# Простой запуск — агент сам задаст вопросы
python agent.py "девочка-волшебница спасает кота из горящего дома"

# С параметрами
python agent.py "космический корабль входит в червоточину" \
    --style cinematic \
    --scenes 5 \
    --duration 6 \
    --aspect 16:9

# Пропустить уточнения (если торопишься)
python agent.py "кот танцует под лофи" --no-questions
```

### Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--style` | cinematic / anime / 3d / realistic / cartoon | cinematic |
| `--scenes` | сколько сцен в видео | 4 |
| `--duration` | длительность одной сцены (сек) | 6 |
| `--aspect` | соотношение сторон | 16:9 |
| `--keyframes` | auto / 1 / 2 / 3 — сколько ключевых кадров на сцену | auto |
| `--out` | папка для результатов | `output/` |
| `--no-questions` | пропустить интерактивные уточнения | false |

## Как пользоваться результатом в Grok

1. Открываешь `output/<slug>.md`
2. Для каждой сцены берёшь блок **«Промт для картинки»** → вставляешь в
   Grok Imagine → получаешь ключевой кадр
3. Тот же кадр + блок **«Промт для анимации»** → image-to-video в Grok →
   получаешь готовый клип
4. Если есть реплики — записываешь голос (сам или через ElevenLabs) по
   блоку **«Реплики»**
5. Склеиваешь клипы в любом редакторе

## Структура

```
agent/
  __init__.py
  llm.py              # обёртка над Claude (подписка → fallback API)
  clarify.py          # стадия уточняющих вопросов
  script.py           # идея + уточнения → сценарий
  prompt_builder.py   # сцена → image-промт + animation-промт
  models.py           # Scene, VideoProject, DialogueLine
  cli.py              # точка входа
prompts/
  system_clarify.md         # промт продюсера-уточнителя
  system_script.md          # промт сценариста
  system_image_prompt.md    # промт для ключевых кадров
  system_animation_prompt.md # промт для image-to-video
  styles.json               # пресеты стилей
output/                     # результаты
```
